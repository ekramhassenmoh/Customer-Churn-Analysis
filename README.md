# Telco Customer Churn Analysis

This project analyzes a Telco customer dataset to identify drivers of churn and provide actionable business insights.

## Key Activities
- Calculated KPIs: churn rate, revenue at risk, average tenure
- Performed exploratory data analysis (EDA) with visualizations
- Segmented customers by value and churn risk
- Built a logistic regression model (79% accuracy, 0.83 ROC-AUC) to predict churn
- Provided actionable recommendations for targeted retention strategies
